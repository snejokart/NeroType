# Соответствие техническому заданию

Источник: «Киберрывок 2026. Отборочный этап», кейс «Печать героя», 4 страницы.

| Требование | Реализация |
| --- | --- |
| Слова 2–10 букв | Фильтрация русских и английских словарей в `lib/corpus.ts` |
| Предложения RU / EN | Подбор связных предложений на выбранном языке |
| Python, JavaScript, HTML/CSS | Режим «Код», отдельный выбор языка |
| Сочетания символов | Режим «Символы», сложность меняет набор знаков |
| Выбор раскладки | Русский / English, соответствующая клавиатура |
| Посимвольный текст и подсветка | Текущий символ, верные символы, красный сигнал ошибки |
| Подсказки по пальцам и рукам | Цветная клавиатура, следующий палец, домашний ряд, памятка |
| Ошибки и пропуски | Ошибочный ввод не продвигает курсор; вставка блокируется |
| Очки и комбо ×2/×3/×5 | Общая логика клиента и сервера в `lib/game.ts` |
| Опыт, уровни, открытие сложности | Серверный XP, квадратичная шкала, режимы и сложность по уровням |
| Достижения | 9 целей, в том числе 1000 верных подряд и 300 WPM |
| Случайные бонусы | XP ×2 на 10 секунд после случайного порога |
| Анимация и визуальная обратная связь | Курсор, ошибки, подсветка клавиш, светящееся комбо, бонус, прогресс, уведомления |
| Статистика сессии | WPM / CPM, точность, ошибки, комбо, очки |
| Общая статистика | Число занятий, общее время, рекорды и история |
| Анализ сложных букв и сочетаний | Частота ошибок на ожидаемых символах и парах |
| Графики дней / недель | Recharts: 7 и 14 дней, скорость и точность, без вымышленных данных |
| Регистрация / авторизация | Email и пароль, гостевой режим, хеши паролей и серверные сессии |
| Хранение и синхронизация | SQLite локально / D1 на сервере; вход с другого устройства к общей базе |
| Восстановление прогресса | Повторный вход по email и паролю |
| Рейтинг скорости, точности, XP | Три сортировки, доступные зарегистрированным участникам |
| Сегодня / неделя / всё время | Серверная фильтрация результатов по времени |
| Адаптивность | Мобильная навигация, гибкая сетка, экранная клавиатура |
| Исходники и инструкция запуска | Git-репозиторий, README, START.cmd, scripts/hero.mjs |

Отправка жюри выполняется участником. В ТЗ указан срок 20 октября 2026, 22:00 МСК (21 октября, 02:00 Красноярск). Название команды и участников в проекте не выдуманы.
