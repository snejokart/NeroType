# Шрифты интерфейса

Файлы хранятся в `public/fonts/` и загружаются с сервера приложения. Подключения к сторонним сервисам при открытии страницы не требуется. WOFF-файлы содержат полные исходные шрифты, включая кириллицу и переменную толщину начертания.

- **Onest** — основной интерфейс. [Официальный источник](https://github.com/google/fonts/tree/main/ofl/onest).
- **Unbounded** — заголовки. [Официальный источник](https://github.com/google/fonts/tree/main/ofl/unbounded).
- **JetBrains Mono** — упражнения, числовые показатели и клавиатура. [Официальный источник](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono).

Шрифты распространяются по SIL Open Font License 1.1. Лицензии каждой семьи сохранены рядом с файлами. Полные TTF из репозитория Google Fonts преобразованы в WOFF с помощью FontTools без удаления глифов.
