# Печать героя

Рабочий прототип по кейсу «Тренажёр слепой печати с геймификацией»

## Быстрый запуск

Нужен **Node.js 22.13 или новее** с npm. При первой установке зависимостей нужен интернет. После установки тренажёр, база, графики и звук работают локально без внешних сервисов.

```powershell
cd HeroType
node scripts/hero.mjs setup
node scripts/hero.mjs start
```
Сайт доступен по ссылке **https://nerotype.kaevanika.workers.dev/**. (ТРЕБУЕТСЯ VPN)

Открыть **http://127.0.0.1:5173**. В Windows можно запустить `START.cmd`: при необходимости он установит зависимости, соберёт приложение, создаст базу и запустит сервер. Первую подготовку не прерывать. Остановить сервер: `Ctrl+C` в его терминале.

Для проверки собранной версии: `node scripts/hero.mjs build`, затем `node scripts/hero.mjs serve`. Разработка и собранная версия используют одну локальную базу. Одновременно на порту 5173 должен работать один сервер.

## Что умеет приложение

- Четыре режима: случайные слова длиной 2–10 букв, связные предложения, код Python / JavaScript / HTML и CSS, случайные сочетания символов.
- Русская и английская раскладки; тренировки на 15, 30, 60 и 120 секунд; три сложности.
- Подсветка введённого и текущего символа, ошибка без продвижения курсора, автоматическая прокрутка текста, цветные зоны пальцев и подсказка следующей клавиши. Код использует английскую клавиатурную подсказку.
- Живые WPM, CPM, точность, ошибки, комбо, очки и случайный бонус двойного опыта на 10 секунд. Звук клавиш из предоставленного MP3 включён по умолчанию; кнопка в тренировке отключает его. Файл хранится локально в проекте.
- Уровни, открытие режимов и сложности, 9 достижений, цель на день и серия тренировочных дней. Закрытые режимы можно попробовать без XP и рейтинга.
- Графики скорости и точности за 7/14 дней, история занятий, разбор трудных символов и сочетаний. Данные на графиках появляются после настоящих тренировок.
- Гостевой режим, регистрация по email и паролю, повторный вход и восстановление прогресса. При регистрации гостевой аккаунт превращается в обычный с сохранением результатов.
- Общая таблица зарегистрированных участников: скорость, точность, XP; периоды «сегодня», «неделя», «всё время».
- Адаптивный интерфейс, ввод с физической или экранной клавиатуры, режим фокуса и поддержка reduced motion.

## Для демонстрации жюри

1. Откройте главную страницу. Выберите 15 секунд и напечатайте несколько слов. Специально ошибитесь: курсор останется на ожидаемом символе, ошибка засчитается, комбо сбросится.
2. После истечения времени посмотрите результат, XP и первое достижение. Откройте «Мой прогресс»: появятся история, график и анализ ошибок.
3. Создайте аккаунт. Прогресс гостевой тренировки сохранится. Выйдите и войдите снова, чтобы показать восстановление данных.
4. Завершите тренировку с минимум 10 верными символами. В таблице лидеров появится аккаунт. Переключите сортировку и период.
5. Попробуйте предложения, символы и код; переключите язык кода. На низких уровнях это ознакомительные тренировки с явной пометкой.

## Стек и устройство

React 19, TypeScript, Vinext / Vite, Recharts, Cloudflare Worker API, Drizzle, SQLite / Cloudflare D1. Технологический стек выбран в рамках разрешённого ТЗ свободного выбора технологий. Локальную SQLite запускает Miniflare, аккаунт Cloudflare для локального запуска не нужен. На хостинге используется D1 и та же схема данных.

```text
app/page.tsx                 интерфейс и жизненный цикл тренировки
app/minimal.css                 оформление и адаптивная сетка
components/typing-keyboard   раскладки, зоны пальцев, Shift-подсказки
app/api/[...path]/route.ts   JSON API
lib/game.ts                 общий reducer ввода и расчёт результатов
lib/corpus.ts               генерация слов, предложений, символов и кода
lib/profile.ts              статистика, история, достижения и серии дней
lib/server.ts               сессии, пароли и доступ к базе
db/schema.ts                схема Drizzle
drizzle/                    SQL-миграции и метаданные
tests/                      проверки игровой логики и API
scripts/hero.mjs             установка, миграции и запуск
```

## Правила расчёта

CPM = число верных символов / время в минутах. WPM = CPM / 5. Точность = верные / (верные + ошибки) × 100%. Пробелы, отступы, переводы строки и пунктуация учитываются. Ввод не требует удаления ошибки: достаточно нажать верную клавишу. Backspace игнорируется; Enter и Tab вводят перевод строки и отступ в коде.

Верный символ даёт 5 очков и 1 XP. Комбо от 10 / 25 / 50 символов даёт множитель очков ×2 / ×3 / ×5. Бонус XP появляется после случайного порога в 30–60 верных символов и действует 10 секунд. Он не завышает WPM. Опыт для уровней: 0, 100, 400, 900, 1600… Предложения открываются на 2 уровне, символы и сложная тренировка — на 3, код — на 4.

Сервер воспроизводит журнал ввода на исходном тексте, проверяет порядок и время событий, владельца упражнения и длительность. Повторная отправка результата не создаёт копию и не удваивает XP. Ограничение скорости — 2500 CPM. Это проверка целостности прототипа; полноценный антибот для соревновательного сервиса потребует дополнительной разработки.

Рейтинг включает зарегистрированные аккаунты, обычные тренировки длительностью от 14 секунд и минимум 10 верных символов. WPM/CPM — лучший результат за период, точность — доля верных нажатий, XP — сумма за период. «Сегодня» определяется часовым поясом браузера, «неделя» — последние 7 суток. Ознакомительные тренировки в рейтинг не входят.

## Аккаунты и данные

Пароли хешируются PBKDF2-SHA256, 100 000 итераций, с отдельной случайной солью. Случайные сессионные токены хранятся в базе в виде SHA256-хеша; cookie HttpOnly, SameSite=Lax, Secure при HTTPS, срок 30 дней. API использует параметризованные SQL-запросы, проверяет Origin и ограничивает попытки входа. Email не публикуется в рейтинге. Подтверждение email и сброс забытого пароля через почту в прототип не входят; восстановление прогресса работает через повторный вход с известным паролем.

SQLite и локальные данные находятся в `.wrangler/state/`, эта папка исключена из Git. База на хостинге отдельная, локальные результаты в неё автоматически не переносятся.

Браузер хранит только настройки и очередь результата при ошибке сети. После восстановления соединения результат можно отправить повторно; очередь автоматически проверяется при следующем открытии страницы тем же аккаунтом. Незавершённые упражнения не начисляют XP.

## Оформление

Темы: светлая и тёмная, переключатель с солнцем и луной находится в шапке. По умолчанию включена тёмная тема. Выбор сохраняется локально в браузере и применяется до первого отображения страницы.
